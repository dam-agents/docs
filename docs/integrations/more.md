# And More

DAM supports a wide range of integrations beyond Slack and GitHub. Connect any service your agent needs.

## Messaging Channels

| Channel | Description |
|---------|-------------|
| **Telegram** | Chat with your agent via a dedicated Telegram bot (you bring your own bot token) |

## Google Workspace

Connect individual Google services to let your agent access them on your behalf:

| Service | What It Enables |
|---------|-----------------|
| Gmail | Read, send, and manage email |
| Calendar | Read, create, and manage events |
| Drive | Access and manage files |
| Docs | Read and edit documents |
| Sheets | Read and write spreadsheets |
| Slides | Read and edit presentations |
| Forms | Access form responses |
| Meet | Manage meetings |
| Tasks | Read and manage tasks |
| Admin | Manage users and groups |
| Analytics | Access report data |
| Search Console | View search performance |
| Photos | Access photo libraries |
| YouTube | Manage channels and videos |

## Other OAuth Providers

| Provider | Description |
|----------|-------------|
| **Spotify** | Access Spotify APIs |
| **Generic OAuth** | Connect **any** OAuth 2.1 provider — supply the auth URL, token endpoint, and your client credentials |

With Generic OAuth, you can connect services like Linear, Jira, Notion, or anything that supports OAuth 2.1 authorization code flow.

## How to Connect

All integrations are configured via **Connections** in the DAM UI. See [Credentials](../features/credentials.md) for setup instructions.
