# Contact

## Slack

Join [**#dam-community**](https://ibm.enterprise.slack.com/archives/C0B3F03NB24){:target="_blank"} on IBM Slack for:

- Questions and help getting started
- Feature requests and feedback
- Announcements and updates

## Bugs and Feature Requests

File them on [github.com/dam-agents/dam](https://github.com/dam-agents/dam/issues){:target="_blank"} so they don't get lost in a channel scroll. For corrections to these docs, open an issue on the docs repo.

## Request Access

Don't have access yet? [Join the waitlist](https://ibm.biz/dam-waitlist){:target="_blank"}.

!!! note "Can't reach DAM?"
    DAM requires the [TUNNELALL VPN](https://w3.ibm.com/#/support/article/troubleshoot_secure/connect_issue){:target="_blank"}. If the site won't load at all, check that first.
