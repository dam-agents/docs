# Contact

## Slack

Join [**#dam-community**](https://ibm.enterprise.slack.com/archives/C0B3F03NB24){:target="_blank"} on IBM Slack for:

- Questions and help getting started
- Feature requests and feedback
- Announcements and updates

## Bugs and Feature Requests

File them on [github.com/dam-agents/dam](https://github.com/dam-agents/dam/issues){:target="_blank"} so they don't get lost in a channel scroll. For corrections to these docs, open an issue on the [docs repo](https://github.ibm.com/dam-agents/docs/issues){:target="_blank"}.

## Request Access

Don't have access yet? [Join the waitlist](https://ibm.biz/dam-waitlist){:target="_blank"}. The form lets you request access for teammates as well as yourself.

You'll also need a model provider key — see [Create your LiteLLM key](litellm-key.md).

!!! note "Can't reach DAM?"
    DAM requires the standard IBM VPN. If the site won't load at all, check that first.

## DAM in Your Slack Workspace

Using DAM in Slack — connecting a channel to an agent, or acting in Slack through a Slack connection — needs DAM's Slack app installed in that workspace, and not every workspace has it. To request it, submit the [DAM Slack request form](https://ibm.biz/dam-slack-request){:target="_blank"}. See [Is DAM in your Slack workspace?](../integrations/slack.md#is-dam-in-your-slack-workspace).
